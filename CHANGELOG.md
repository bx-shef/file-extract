## 0.2.0 — 2026-10-24

Доработки по ревью панели (bx-shef/file-extract#2). Версия разборщика `0.2.0-1` — старый кеш
не отдаётся.

- Адрес разбора — `POST /v1/extract` (старый `/extract` убран, клиентов не было); ответ несёт
  `extractorVersion`.
- Безопасность: `x.constructor`/`x.__proto__` больше не считаются форматом; путь CSV из вывода
  LibreOffice — только внутри своего каталога и по последней стрелке; LibreOffice со свежим
  профилем (макросы выключены, ссылки и внешние картинки не грузятся, связи не обновляются)
  вместо `--safe-mode`, который этот профиль отбрасывал; `HOME`/`XDG_*`/`TMPDIR`/cwd процессов —
  рабочий каталог разбора.
- Бомбы: картинка больше 50 Мпикс — отказ до OCR; лист CSV больше 50 МБ — отказ до чтения;
  `pdftotext -l 500`.
- Нагрузка: `MAX_QUEUE` (8) — переполнение очереди сразу `503`; тела в памяти не больше
  «разборы + очередь»; `maxConnections`. Уход клиента прерывает разбор и ожидание
  (`client_aborted`, не `500`). После `401`/`413`/`503` соединение закрывается.
- Процессы: группа добивается и после обычного завершения (не остаётся `soffice.bin`).
- Кеш: ключ учитывает расширение и `MAX_TEXT_CHARS`; дисковый кеш ограничен
  `CACHE_MAX_BYTES` (256 МБ); сбой создания каталога больше не закрывает кеш до перезапуска.
- Обрезка текста не режет суррогатную пару.
- Умолчания: `HOST=127.0.0.1` (в образе `0.0.0.0`), `EXTRACT_TIMEOUT_MS=300000`.
- Журнал: `queueMs`, `errorClass` для `500`, событие `cache_sweep_failed`.
- Образ: `node:22-slim` по digest, `USER 1000:1000`. Compose — под ВМ портала (1 ядро, 1,5 ГБ,
  один разбор), отдельный tmpfs под кеш, `noexec,nosuid,nodev`, образ по тегу sha.
- CI: `packages: write` только у джобы публикации на `main`, `persist-credentials: false`;
  Dependabot для npm, actions и docker.
- Тесты: журнал (ровно разрешённые ключи), 413 и закрытие соединения, срок кеша, временные
  каталоги, `503 busy`, уход клиента, интеграционный тест на настоящих программах.

## 0.1.0 — 2026-10-24

Первая версия (bx-shef/file-extract#1).

- Разбор перенесён из ai-price-import без смены смысла: TXT/CSV/TSV (UTF-8 или windows-1251),
  PDF через pdftotext с откатом на OCR для сканов, Office через LibreOffice (каждый лист в свой
  CSV, до 64 листов), картинки и сканы PDF через Tesseract rus+bel+kaz+eng (до 30 страниц),
  очистка текста в одной точке.
- `POST /extract` (тело — файл, имя — `X-File-Name`) и `GET /health`.
- Листы таблиц в ответе (`sheets: [{name, csv, rows}]`), признаки `ocr`, `truncated`, `pages`.
- Общий ключ вызова `EXTRACT_API_KEY`, сравнение за постоянное время; без ключа сервис не стартует.
- Кеш на 24 часа (Redis или диск), ключ с версией разборщика.
- Ограничение одновременных разборов с очередью, таймаут на файл с убийством группы процессов.
- Журнал без имён файлов и текста.
- Docker-образ с проверкой программ при сборке, пример compose с изоляцией, CI с публикацией в GHCR.
